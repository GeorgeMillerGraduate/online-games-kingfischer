How to read this workbench

Search scores favour the side to move internally; the main score and chart are shown from White’s perspective. Mate scores are search results, not promises about unfinished depths.

Each completed root iteration evaluates all legal first moves. The three boards show the best completed candidates; a partial deeper iteration does not replace them. “One depth” starts a new search capped one depth beyond the last completed search.

Classic evaluation is a new, explainable browser mode. Optional NNUE uses the supplied Java engine’s feature architecture and weights. Browser search is an adaptation, not a byte-for-byte port of every Java heuristic.
