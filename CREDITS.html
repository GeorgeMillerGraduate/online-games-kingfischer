Sources & credits

Engine and browser port

Based on the KingFischer2 Java source supplied by George Miller. Original source is included under reference/java/. JavaScript adaptation, graphics and browser integration prepared for JengaCode. Distributed under GPL-3.0-or-later.

The supplied engine contains Stockfish-derived code and NNUE architecture. Retain NOTICE.md and STOCKFISH-AUTHORS. See Stockfish source and NNUE training tools. The included nn-1a298aa575a0.nnue weights are copied unchanged from the supplied Java project.

Port status and actual validation results. This browser search is not identical to Stockfish or to every heuristic in the Java search. Effort levels are not measured Elo ratings.

Chess pieces

Cburnett SVG chess pieces by Colin M. L. Burnett, obtained from the official Lichess lila collection, GPLv2 or later as recorded in the upstream COPYING file. SVG source files are included in assets/pieces. The app uses the simple, legible Lichess style; it is not affiliated with Lichess. Lichess logos and proprietary branding are not used.

jQuery 3.7.1 by the OpenJS Foundation and contributors, MIT licence. Served locally; source provenance: jquery.com.

Artwork

Kingfisher, chess king and imagined Victorian Bobby Fischer portrait: original AI-generated editorial artwork created for JengaCode, 31 October 2026. The portrait is an artistic interpretation, not a historical photograph. All interface text, chess diagrams, scores and statistics are rendered from HTML/SVG and actual game/search state.

The compass emblem is an original inline geometric drawing for this package. Fonts use system Georgia and Arial; no font downloads.
